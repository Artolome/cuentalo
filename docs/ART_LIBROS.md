# Décors de « Libros y artistas »

Quatre illustrations originales créées avec l'outil intégré ImageGen, le 15 octobre 2026. Sources PNG conservées dans `src/art/assets/escenas-cartoon/`, versions WebP intégrées au jeu (1024 × 640, qualité 80). Les rendus ont été inspectés avant intégration : premier plan libre, aucun texte lisible ou personnage, quatre ambiances distinctes. Ce sont des évocations dessinées, pas des reconstitutions exactes des lieux.

Les neuf autres décors sont documentés dans [ART_CULTURAS.md](ART_CULTURAS.md). Les références culturelles se trouvent dans [FUENTES_CULTURALES.md](FUENTES_CULTURALES.md).

Inviting afternoon light. No people, no horses, no monsters, no letters, no signage, no logos, no borders, no UI, no watermark. Only this background.
